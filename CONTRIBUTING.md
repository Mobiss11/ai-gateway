# Контрибьютинг

Спасибо за интерес к ai-gateway!

## Разработка

```bash
git clone https://github.com/Mobiss11/ai-gateway.git
cd ai-gateway
uv sync --extra dev
uv run pytest -q
```

## Правила

- **Тесты обязательны** к любому поведению: HTTP-часть проверяется через
  `httpx.MockTransport`, сеть в тестах не используется.
- **Секреты** — только фиктивные значения в фикстурах и примерах
  (`test-gateway-token`, `sk-…`-заглушки). Реальные ключи, IP и
  персональные пути не коммитятся.
- **Прозрачность** — поведение шлюза описано в README и
  `docs/architecture.md`: если меняете перевод формата, кэш-брейкпоинты
  или обработку ошибок — обновите документацию в том же PR.
- **Стиль** — как в существующем коде: python 3.13+, docstrings на русском
  в стиле модуля, типизация аннотациями.

## PR

1. Форк → ветка → изменения + тесты.
2. `uv run pytest -q` — зелёный.
3. Описание: что меняет, зачем, как проверено.

Багрепорты — в Issues: версия, конфиг без секретов, ожидание/факт.
